Pair this device

Create an expiring owner or guest token in Bruhs on the host, then paste it here. Connect through SSH, your private network, or your own HTTPS proxy. There is no hosted relay. The token stays in this tab's session.

On a phone, use your browser's Add to Home Screen or Install app action. Reopen and pair if the browser has ended its session. The host must stay awake.

Arrow keys move between cards. Press N for a new task.

Resume from pull request events

Approve which changes from an existing Delivery watch may continue this task. It keeps its current model, project and access. Review text never grants extra permission to publish or merge.

Event receipts

Events wait behind a busy task. Stopping a task disables its subscriptions. Interrupted or uncertain reserved turns are never replayed; inspect and resume them yourself. The bounded journal retains deduplication receipts until its task is deleted.

An approved watch also links its pull request to this task on the board.

A new worktree gives the task its own branch, so its pull requests appear on its card.

Compare models

Each model gets its own worktree and the same task.

Each turn pins its specification revision. A changed specification applies when you send the next message. Running work keeps its pinned revision visible.
