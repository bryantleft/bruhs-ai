ACP agents

Add an installed Agent Client Protocol command. The agent keeps its own login and tools. Bruhs negotiates ACP v1, streams replies and tool activity, and relays permission requests. Agent-native modes are not an operating-system sandbox.

After saving, select acp/instance-id/model-id in the composer or task model field. Use default for the agent's default model.

Add or update an agent

Arguments are literal; shell expressions are not evaluated. Leave a mode blank to make that access mode unavailable. Full access requires an explicit selection. Sign in using the agent's own command in a terminal.
