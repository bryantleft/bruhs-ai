Remote hosts

Keep an SSH tunnel to your own task host. OpenSSH uses your existing keys and known-host records. The forwarded page still requires its own pairing grant.

Add or edit a host

Connect starts one reviewed foreground tunnel bound to 127.0.0.1. Bruhs never accepts an unknown host key, asks for a password, rewrites SSH config or reconnects automatically after restart. Establish trust and verify noninteractive login in a terminal first. Use an SSH alias without additional forwarding directives.
