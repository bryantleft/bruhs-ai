Privacy

This page covers the bruhs.ai website and the downloads it links to. The bruhs app keeps your data on your device; the privacy section of the home page lists what goes online.

The website

The site has no forms, no cookies, no analytics and no tracking pixels. It is hosted on Vercel, which keeps standard request logs (such as IP address and time) for operating the service.

Downloads and updates

Downloads and source code come from GitHub, under its own privacy statement. The app checks GitHub for a newer release, and npm or Homebrew for newer Claude Code and Codex CLIs, unless you turn off Check for updates in Settings → Updates. Those checks send no account or usage data.

Questions

Email privacy@bruhs.ai, or open an issue on GitHub.
