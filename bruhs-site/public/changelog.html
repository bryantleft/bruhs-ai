What's shipping,
week by week.

No testimonials yet, so here's what we built instead. Each entry covers one week of the private test build, newest first.

Week 44 · 2026

Oct 26 – Nov 1

Private testingLatest

You can redirect Claude mid-reply, and a coding thread can run in its own worktree and rewind to any message.

Added

  • Added Steer to redirect Claude mid-reply, and /compact with auto-compact for long Claude threads, on web and desktop.
  • Added a choice to start a project thread in the current checkout or a new worktree, with shortcuts to pick the branch and Claude's effort.
  • Added Edit from here to rewind a thread to before a message, and in worktree threads to restore the files as they were then.
  • Added file and image attachments by paste or drop, and a web viewer that opens images, audio, HTML, and PDF beside the conversation.
  • Added a Files tab beside the chat, and a link to the branch's GitHub pull request when the gh tool is signed in.
  • Added selecting a range of a live transcript to copy or delete it, on web and desktop.

Changed

  • Made diffs easier to review, with a filter for code, tests and docs, per-file viewed marks, and ⌘F find.
  • Made threads easier to sort, with snooze, a Working section, and five seconds to undo a move.
  • Made queued follow-ups editable, and let ↑ in an empty composer bring back the prompts you sent earlier.
  • Made the composer style Markdown as you type and turn very large pastes into attachments.
  • Made every shortcut editable under Settings, Keybindings, with ⌘[ and ⌘] now moving back and forward between pages.
  • Made small controls easier to hit and raised the contrast of secondary text on web and desktop.

Week 41 · 2026

Oct 5 – 11

Private testing

The access-mode menu now explains what each mode lets Claude or Codex do.

Changed

  • Made the access-mode menu describe each mode for the selected model, and explained in the chip's tooltip why Codex can't edit files in Default.

Week 40 · 2026

Sep 28 – Oct 4

Private testing

Live meetings now shrink into a small movable dock, and a reliability pass closed many ways a save or recording could fail silently.

Added

  • Added a compact meeting dock with live status and Stop, as a movable panel with a transcript preview on web and a floating window on desktop.
  • Added Chat and Code tabs at the top of the workspace, separating general conversations from project threads, on web and desktop.
  • Added an opt-in record of which app was in front during each recording on desktop, kept on your device and limited to app names.
  • Added a warning before you close a tab with unsent text, unsaved changes, or a reply still streaming.

Changed

  • Made streaming replies in long threads far lighter on web and desktop by redrawing only the reply being written.
  • Made the command bar faster as you type, and kept long thread lists and large note libraries quick.
  • Changed Codex to run read-only in Default mode, because it can't ask before editing. Choose Auto-accept when you want it to write.
  • Blocked other websites from reaching bruhs on your machine, and stopped replies from loading raw HTML, unsafe links or remote images.
  • Kept unsaved task and contact drafts when you move to another page, and kept your current work when saved threads fail to load.
  • Made the desktop app stay responsive while it reads git status, switches branches or lists files.

Fixed

  • Fixed saves that could leave half a record behind. Every kind of item now saves completely or not at all.
  • Fixed recordings marked complete after losing audio or transcript lines. The meeting now shows what failed.
  • Fixed Stop hanging, live timestamps running about three times too fast, and the same meeting recording twice.
  • Fixed branch switching that could discard uncommitted edits when a branch name matched a file path.
  • Fixed a stopped Codex turn that kept editing files, and Claude turns that hung after hitting a limit or failed without saying why.
  • Fixed Google Calendar sign-ins that were never saved, so the connection now survives a restart.

Week 38 · 2026

Sep 14 – 20

Private testing

Meeting notes became editable, and live meetings now recover cleanly from dropped connections and restarts.

Added

  • Added meeting notes you write and edit yourself, which can link to a recording, on web and desktop.
  • Added recovery for meeting summaries, so one started before a reload or disconnect can be picked up later or cancelled.

Changed

  • Changed auto-record's microphone activity checks to need your opt-in each app session, with a Settings switch to turn them off.
  • Stopped renaming transcript speakers from names read off the screen, since a visible name doesn't prove who is talking.

Fixed

  • Fixed live transcripts falling out of sync after a dropped connection, on web and desktop.
  • Fixed accented letters, emoji, and other non-Latin text getting garbled in live desktop updates.
  • Fixed speaker matching that gave up after a brief failure or a restart, so it now picks up where it left off.
  • Fixed false recording errors when the live meeting feed fell behind.
  • Fixed stacked notifications covering workspace controls, and made desktop notifications dismissable from the keyboard.

Week 37 · 2026

Sep 7 – 13

Private testing

Today, Life, Inbox and Knowledge arrived, with one shortcut to capture anything and one search across all of it.

Added

  • Added Today (⌘⇧Y), one view of your schedule, focus tasks, overdue work and meeting decisions, with Plan my day to preview focus blocks.
  • Added Life, a private finance ledger and health journal with budgets, CSV import, workouts, sleep, and habits, hidden from the agent until you opt in.
  • Added Inbox for conversations you bring in from other apps, and Knowledge for Markdown notes and web clips that keep their source.
  • Added Smart scheduling, which turns task estimates into focus blocks, plus local booking links, and asks before a Google change overwrites a local edit.
  • Added Capture anything (⌘⇧Space) for quickly saving a task, note, event, contact, or message draft from anywhere.
  • Added agent workflows that preview a multi-step change you can undo, and on desktop, let other agents propose changes over MCP for you to approve.

Changed

  • Made ⌘⇧F search everything in bruhs, ranked as you type.
  • Moved meetings, transcripts, and contacts into a private database on your device, so they survive a server restart.
  • Made desktop dialogs and line wrapping match the web app.

Week 36 · 2026

Aug 31 – Sep 6

Private testing

Chat now runs on a live timeline with diffs, a terminal and tool approvals, and the macOS app matches the web app.

Added

  • Added tool approval prompts, so Claude asks before running a tool and you approve or decline from the composer, on web and desktop.
  • Added a diff panel that shows each turn's changes or all uncommitted ones, with syntax highlighting and Open in editor (⌘O).
  • Added a terminal drawer (⌘J) and a Terminal view on web and desktop, with web tabs that keep their scrollback across reloads.
  • Added a Preview panel (⌘⇧J) that finds dev servers running on your machine and shows them beside the chat.
  • Added a queue for prompts typed while a turn runs, and a prompt stash (⌘S) for drafts you want to keep.
  • Added pinned and settled threads, and shortcuts for new threads, switching threads, mentioning files and search.

Changed

  • Rebuilt the chat as a timeline that groups tool activity and folds finished turns behind "Worked for…".
  • Redesigned the workspace into three columns, with a sidebar of thread cards you can filter by project and a resizable right panel.
  • Redesigned the composer around the model, access mode and current branch.
  • Moved Settings to a full page with sections.
  • Made each thread resume its Claude or Codex session, so earlier turns stay in context, and name itself from your first message.
  • Brought the macOS app level with the web app, from chat to calendar, meetings and settings.

Fixed

  • Fixed the Monaspace font not loading, and sixteen desktop icons that never appeared.
  • Fixed desktop controls that took focus without showing a focus ring, and a People expander you couldn't reach from the keyboard.
  • Fixed the right panel squeezing the chat on narrow windows.
