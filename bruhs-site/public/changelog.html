November 9, 2026

v0.1.0

Current

The first public release: a local-first agent for your whole day, as a signed Mac app and a web app that both run on your machine.

Added

  • Agent threads with Claude Code and Codex, on your own logins: a live timeline that folds finished turns, tool approvals, Steer to redirect Claude mid-reply, /compact, queued follow-ups, and a prompt stash (⌘S).
  • Project threads in the current checkout or a new worktree, with Edit from here to rewind a thread and its files to an earlier message.
  • A diff panel with a code, tests and docs filter, viewed marks and ⌘F find; a terminal drawer (⌘J); a preview panel (⌘⇧J) for local dev servers; and a Files tab.
  • Thread import from Claude Code, Codex, T3 Code and Cursor, and Continue in Claude Code, Codex or T3 Code, or copy a thread as Markdown.
  • Today (⌘⇧Y): your schedule, focus tasks, overdue work and meeting decisions, with Plan my day to preview focus blocks you can undo.
  • Tasks and a calendar with Smart scheduling, local booking links, and read-only Google Calendar sync.
  • Meetings: on-device recording of your microphone and the other side of the call, Whisper transcription with live previews, speaker labels and voice identity across meetings, summaries, editable notes, and a compact live meeting dock.
  • People, Knowledge (Markdown notes and web clips), Inbox, and Life, a private finance ledger and health journal hidden from agents until you opt in.
  • Capture anything (⌘⇧Space) and search across everything (⌘⇧F).
  • Agent workflows that preview a multi-step change you can undo, and an MCP server that lets other agents propose changes for you to approve.
  • Private credential requests: agents ask for a secret through a separate form, and the value goes to your keychain, never into the chat.
  • Settings → Updates: update checks for the Claude Code and Codex CLIs with one-click updates, and for bruhs itself.
  • The Mac app (macOS 13 or later, Apple silicon), signed and notarized. It starts its own server and meeting-capture daemon, and installs its updates when you choose Restart to update.
  • Editable keyboard shortcuts for every action, and a command bar (⌘K).
